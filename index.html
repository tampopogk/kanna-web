macOS app for coding agents

KANNA

Apple Silicon Intel

Requires macOS 15 or later

// WHAT IT DOES

  • Composed workflows

    Named stages, an agent assigned to each one, automatic or human-controlled transitions, and a revision limit — checked into the repository as a versioned file.

  • One durable task

    A task keeps its identity and instruction history through every stage, while each stage gets a fresh branch and worktree from the last committed tip.

  • Coordinators

    Long-running task-manager and merge roles coordinate repository work. A review dispatcher sends one change to the applicable specialists in parallel, then reconciles their verdicts.

  • Agent per stage

    Run Claude Code, Codex, GitHub Copilot CLI, OpenCode, or Antigravity — whichever suits the stage.

  • Away from the desk

    Follow task-linked notifications, inspect state and diffs, send input, and advance eligible stages from your phone. Move a task between reachable Kanna machines.

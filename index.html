Composed workflows

Give autonomy a shape.

Compose stages around the way your repository actually ships. Kanna keeps agents moving when the next step is known—and brings you in when judgment matters.

01

Repo-defined, staged work

Define the stages, automated transitions, and human checkpoints each task follows. The workflow stays with the repository, not in someone’s memory.

02

Isolated by design

Every task runs in its own git worktree, so multiple agents can work at once without sharing an accidental working state.

03

Bring the agents you use

Kanna orchestrates installed agent CLIs instead of replacing them. Keep your chosen tools, models, and repository context.

04

Coordinate the coordinators

Repo-specific coordinator agents can break down work, create follow-up tasks, call specialized reviews, and shepherd work toward completion.
